TAPVORA Sunglasses Update

This package contains the full website index.html based on the existing TAPVORA site, plus 10 individual sunglasses images in the images/ folder. Existing categories and other products are preserved.

Sunglasses prices are suggested retail prices in Bangladeshi taka (৳), informed by current public Bangladesh online listings. They are not verified wholesale costs and can be edited in the sunglassesCatalog array in index.html. Confirm product stock, supplier costs, and UV protection claims before selling.

Upload index.html and the images folder together to the same root folder of your GitHub Pages repository. Keep a backup of your old files first.
